## 🌟 Key Features

- **10–20 Second Recruiter Impact**: Immediate technical clarity on core capabilities, strongest skill (SQL), and enterprise tooling.
- **Interactive Data Engineering Pipeline Visualizer**: 7-stage interactive data lifecycle (`SOURCE` → `INGEST` → `STORE` → `TRANSFORM` → `MODEL` → `SERVE` → `ANALYZE`).
- **6 Comprehensive Real-World Case Studies**:
  1. **Healthcare Enterprise Lakehouse** (Inspired by IHHN, ADLS Gen2, Medallion Architecture, Databricks, PySpark, Synapse, Power BI).
  2. **Flight Data Engineering & Analytics Platform** (DOT On-Time Performance dataset, partitioned ADLS Gen2, Spark transforms, Fabric Warehouse).
  3. **Local Enterprise Distributed ETL Platform** (Spark Master + Workers, Apache Airflow, PostgreSQL, Docker Compose, GitLab & Jenkins CI/CD).
  4. **FinGuard — Streaming Data Engineering** (Kafka, streaming ingestion, real-time transformations).
  5. **Enterprise Sales Data Warehouse** (Kimball Star Schema, Facts & Dimensions, SQL ETL, Power BI, DAX).
  6. **Synthea Healthcare Data Platform** (Synthea synthetic EHR dataset, ADLS Gen2, Spark medallion pipeline).
- **Interactive SQL & Dimensional Modeling Showcase**: Interactive query explorer with Window Functions, CTEs, SCD Type 2 MERGE, Anti-Joins, and Star Schema DDL.
- **Technical Architecture Diagrams**: Interactive SVG cloud blueprints for Azure Medallion, Flight Analytics, Local Docker Clusters, and Microsoft Fabric.
- **Dedicated Microsoft Fabric Section**: OneLake, Fabric Lakehouse, Warehouse, Pipelines, and Direct Lake Power BI.
- **Cloud Security & Access Controls**: Managed Identity, Azure Key Vault secrets decoupling, and RBAC least-privilege patterns.
- **Power BI & Semantic Modeling**: Domain-specific DAX measures across healthcare, aviation, and sales.
- **DevOps & Software Craftsmanship**: Docker Compose, modular Python ETL architecture, and CI/CD testing.
- **Dual Presentation**: In-page interactive modals + dedicated static SSG routes (`/projects/[id]`).

## 🚀 Quick Start (Local Development)

### 1. Clone the repository
```bash
git clone https://github.com/ammarCMD/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```

## 🌐 Deploy to Vercel

The easiest and most recommended way to deploy this portfolio is using **[Vercel](https://vercel.com/)**:

1. Push this repository to your GitHub account (`https://github.com/ammarCMD/portfolio`).
2. Log in to [vercel.com](https://vercel.com) using your GitHub account.
3. Click **"Add New..."** → **"Project"**.
4. Select your **`portfolio`** repository.
5. Click **"Deploy"** (Next.js settings are automatically detected with zero configuration required).
6. Your portfolio is live with automatic global SSL, edge CDN caching, and automatic continuous deployment on every `git push`.
